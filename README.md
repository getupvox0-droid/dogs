# 작은 발자국 / 강아지의 삶

Development version 0.1. Independent browser-local life simulator; no third-party game source or text is included.

## Run and test
Serve dist with any static HTTP server. Run `npm test` using Node 22+.

## Implemented
Seeded serializable PRNG, daily simulation, six uniformly selected countries, country-dependent breed labels, family/street/shelter starts, aging, illustrative mortality hazard, weather, contextual daily events with cooldowns, persistent encounters, trust and adoption, memories, pausing decisions, speed controls, local save, JSON export/import, ending summary.

## Data honesty
ALL birth weights, environment proportions, hazard rates, behavior changes and timings are prototype assumptions. Country selection is uniform exploration, not worldwide dog birth weighting. Breed labels currently have no biological effect. Weather is synthetic and not a historical disaster feed. Eyes/growth scenes are simplified illustration, not validated developmental advice. State scores are prototype variables and are not a clinical model. No expectation-of-life claim is displayed.

These checks do not establish real-world accuracy or browser interaction correctness.

Managed runtime has no control-browser skill, so browser QA is not performed in this increment, per Sites workflow. UI is statically checked only.

## 0.4 lived experiences
Removed the scheduled recurring scent-at-the-end-of-the-path question and repetitive rain prompt. Added 37 single-occurrence choice events across 13 domains, with 2 actions each, contextual age/home/weather gates, effects, habits, later unlocks and delayed follow-ups. Covers puppy chewing/toilet learning, recall, cooperative handling, games, meals, family additions, temporary care/travel, fear/rest signals, street resources and shelter enrichment, aging/accessibility and adapted activities. Care scenes are authored narratives, not medical diagnoses or measured rates. Some choices reflect vulnerability and communication rather than human-like control over outcomes.

Legacy repetitive prompts have lifetime caps. Twenty one-time habit scenes tie daily prose back to choices; daily events use finite authored variants and never repeat an identical text in a life. Legacy saves retain history and initialize new ledgers on continuation. Follow-ups are dropped if their home/area context no longer applies. 29 tests pass, including unique-choice coverage (37 types / 13 domains in 30 simulated lives), chronological consistency, saved consequences, contextual follow-ups, and prose repetition prevention. Browser visual QA remains unavailable.

## 0.5 conditional lives instead of a shared opening script
Birth now has nine authored natal contexts with maternal/hand-reared care, litter composition, food resources, caregiver availability, spatial setting/noise, birth month and individual curiosity/sensitivity/sociability/energy. Context scores and rates are uncalibrated design assumptions, not measured national distributions. Growth physiology remains shared within approximate dog developmental ranges; scene content branches by actual maternal status, litter and setting, while individual milestone dates vary independently. Hand-reared puppies do not nurse/play with an absent mother. No independent street foraging/roaming before day 90 (conservative narrative gate, not a biological threshold).
Replaced modulo-21 ambient, modulo-90 weather, modulo-45 contact and modulo-97 friend clocks with serializable individual calendars. Seasonal synthetic weather expires after a few days; household/resource changes affect care, comfort/stress, resources, eligible activities and weights. Birth origin remains immutable; current living context changes after adoption/moving. Training/play/family events are gated by resources/care/space; personality and stress change event weights. Selected actions update learned traits and resources, and those feed later scheduling. New UI exposes birth/current-life context. Legacy histories remain untouched; future schedules initialize at continuation time.
36 tests pass. In 200 sampled births: all 9 contexts appeared, 155 distinct birth narratives and 200 distinct early histories; first-contact schedules spanned 63 dates. This establishes variation and regression protection, not human-perceived realism or statistical validity. Counterfactual same-seed resource tests verify actual differences in eligible/experienced choices. Browser visual QA remains unavailable.

## 0.7 real reference photo collection
Switched rendered dog images from AI atlases to reviewed Wikimedia Commons photographs. Collected 102 breed-query candidates in two passes, visually inspected contact sheets, rejected place-name/map/building/cat/art matches and unclear dogs, and published 61 local reference photos across the current 10 labels. Count: regional mix 7, Jindo type 6, poodle 6, Shiba type 6, Indian pariah type 8, Labrador type 5, terrier type 4, shepherd type 3, small mix 8, husky type 8. Purebreed photos under mixed labels are explicitly type references, never pedigree claims. Photos are not presented as the player's individual or as age-matched growth records. No per-player image API requests. Each life gets one reference in its timeline (deduplicated), and a collapsible breed photo library shows alternatives. Landing hero also uses a real attributed photo. Original AI files are retained as previous source assets but are no longer rendered by imageFor.
Every used photo has local file, source page, author, license name, license URL when supplied, retrieval date and review flag in dist/data/photo-sources.json; credit/source links appear adjacent to images. Only explicit CC BY / CC BY-SA / CC0 / public-domain candidates were admitted; ambiguous commercial-use requests were excluded. No source photo content was modified; Commons-provided display thumbnails were downloaded. License obligations remain attached to each image, and BY-SA image licenses do not purport to license the whole app. No private-site or arbitrary image scraping.
The collector scripts/collect-commons.py uses Commons search API with 3 workers, timeouts, bounded results and pending-review output under tmp/photo-candidates. Its candidates are not automatically published; release requires visual review and manifest update. Unreviewed downloads are not in the served photo directory.
44 checks pass across the existing suites plus photo metadata/breed matching/dedup tests; all 61 local image files decoded successfully. Browser visual QA remains unavailable.
