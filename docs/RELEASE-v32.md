# 강아지의 삶 v3.2 구현 보고

## 구현
- 메인 타임라인: 최신순, 나이·날짜, 선택과 결과 묶음, 연결 이야기 필터, 40건 페이지 단위 표시. 과거 기록을 읽으면 정지하고 최신 기록으로 돌아와 재개.
- 사건 단위 이야기 진행을 기본으로 적용. 빠른 관찰은 일상 기록을 화면에서 묶으며 원본 기록은 보존. 직접 진행 모드는 다음 사건 버튼 사용. 날짜를 건너뛰는 동안 내부 상태는 매일 계산.
- 허기·갈증: 고정 일일 차감 대신 하루 네 시기의 수요와 실제 섭취를 계산. 월령·체형·활동·더위·질병·물과 먹이 접근성 반영. 신생 개체는 젖의 수분 반영.
- 주변 동물: 지역별 지속 ID, 외형·성별·기질·연령·건강·상호작용 기록. 놀이·경계·호기심·먹이 경쟁·재회·영역·휴식 목적별 상황과 행동.
- 인간과 환경: 돌봄·경제·시간·지식 프로필, 판매점 경로, 단계적 구조, 보호자 변경과 재입소. 결정은 인간이 하고 개의 반응만 선택.
- 의료: 슬개골·귀·피부·치아·노화 관절 문제를 지속 상태로 관리. 증상·발견·진단·보존적 관리 또는 수술·회복·재활 연결. 의료 접근성이 없으면 자동 수술하지 않음. 중성화 중복 방지 및 전신 상태 조건 유지.
- 기존 출생·외형·성장 이미지·엔딩·저장 유지. 신규 구조·보호자 변경·의료 기억도 실제 기록에 있을 때만 엔딩에 반영.

## 주요 파일
`dist/app.js`, `index.html`, `dashboard.css`, `engine.js`, `story-runner.js`, `physiology.js`, `people-world.js`, `neighbors.js`, `clinical.js`, `chronicle.js`; 관련 선택·가족·성장·이미지 모듈. 검증: `tests/v32.test.mjs`, `tests/playback-ui.test.mjs`, `tests/engine.test.mjs`.

## 자료와 한계
슬개골 관리 구분은 ACVS https://www.acvs.org/small-animal/patellar-luxations/ 참고. 발생률·단계 기간·인간 자원 점수는 게임용 가정이며 임상 확률이나 국가 통계가 아니다.

v3.2 전체 요구를 모두 완료했다고 주장하지 않는다. 1,100개 검증 템플릿, 모든 동물 종, 국가별 실측 입양·질병 통계, 주변 동물의 완전한 번식·사망 시뮬레이션, 골절·비만 등 모든 추가 질병은 미완료. 이미지 자산은 기존 유한 집합을 재사용한다. 일부 발달 단계는 표시된 도식 대체 이미지다.

실제 모바일 브라우저 화면 검증은 사용 가능한 브라우저 검증 기능이 없어 수행하지 못했다. DOM 기반 UI 동작 및 자동 엔진 테스트와 구분해야 한다.

## 검증 결과
`node --test tests/*.test.mjs`: 90개 통과, 실패 0개. 출생부터 사망까지 1,000개 생애 반복, 상태 범위·사망 후 진행 방지·환경 조건·저장 복원·외형 일관성·성장·가족·선택 중복 방지 포함. 신규 의료 단계·일일 계산과 사건 단위 진행의 동등성·필요 수치 변화·구조와 보호자 변경 테스트 통과. UI는 모의 DOM 검증이며 실제 화면 검증과 다름.

다음 우선 작업: 실제 모바일 화면 검증, 사건 구성의 반복률 수치화와 다양성 확대, 지역별 자료 보강, 의료·주변 개체 생애 모델 확장.
