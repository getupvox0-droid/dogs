# 개발 로드맵

『80억 분의 1』에서 영감을 받은 "무작위로 태어나는 한 생"을 개의 시점으로 옮긴 게임입니다. 원작을 그대로 따라 하는 대신, 개라서 가능한 경험에 집중합니다.

## 핵심 원칙

1. **강아지는 모르고, 플레이어는 안다.**
   서술은 끝까지 강아지의 감각(냄새, 온기, 소리, 배고픔, 손길)에 머뭅니다. 나라, 지역 현실, 통계 같은 정보는 화면의 별도 영역에서 플레이어에게만 보여줍니다. 갓 태어난 강아지는 집이 따뜻한지, 여기가 어느 나라인지 모릅니다.
2. **강아지는 비교하지 않는다.**
   길에서 태어난 개는 자기가 운이 나쁘다고 생각하지 않습니다. "불쌍하다", "운이 나빴다" 같은 판단은 게임이 내리지 않고 플레이어 몫으로 남깁니다.
3. **숫자는 출처와 함께.**
   실제 통계에는 출처, 연도, 신뢰도를 붙이고, 출처가 없는 값은 "게임용 가정"으로 분명히 표시합니다.

## 1단계: 이 게임만의 정체성

- [x] 감각 서술과 플레이어 정보 분리 (출생 장면부터)
- [x] 이름 붙이기: 가족이 부르는 이름, 동네에서 부르는 이름, 보호소에서 붙인 이름
- [x] 태어날 곳 뽑는 기준 선택: 골고루 둘러보기 / 현실 비율
- [x] 나라별 개 통계 출처 기록 (`dist/birth-odds.js`)
- [x] 우리 집 강아지와 비교 (엔딩)
- [x] 나라 확장: 브라질·멕시코·중국·필리핀·나이지리아·태국을 더해 12개 나라가 됐습니다. 현실 비율에서 한 나라가 30%를 넘지 않고, 미국 가정견은 약 23%입니다.
- [ ] 남은 빈칸: 아프리카는 나이지리아 한 곳뿐이고, 중국·브라질·멕시코의 길·마을 개 수는 게임용 가정입니다. 남반구 계절(호주·아르헨티나 등)과 나라별 토종견 그림도 아직 없습니다.

## 2단계: 다시 할 이유

- [x] 도감: 태어난 곳(나라 × 출생 환경), 삶의 갈래 15가지, 만난 모습(품종), 최근에 살아본 삶. 이 기기에만 저장됩니다.
- [x] "곁의 존재들" 앨범: 엔딩에서 곁에 있던 사람과 개를 처음 만난 때부터 함께한 기간과 함께 보여주고, 도감에 삶마다 가장 오래 곁에 있던 존재를 남깁니다.
- 업적: "길에서 태어나 끝까지 한 가족과 살았다" 같은 기록
- [x] 한 생 길이 선택: 짧게(약 25분) / 보통(약 40분) / 길게(약 1시간), 1배속·보통 읽기 속도·선택 시간 포함. 보여주는 속도만 바뀌고 같은 시드면 같은 삶입니다.
- [x] 읽는 속도: 천천히 / 보통(초당 약 9자) / 빠르게. 선택 결과와 중요한 장면은 다 읽고 누를 때까지 멈춥니다 (관찰 모드는 저절로 넘어감).
- [x] 엔딩 생애 카드: 9:16 스토리 비율, 가장 중요한 순간 3개(드문 순간 우선, 일어난 순서로), 강아지 감각으로 쓴 마지막 한 문장

## 3단계: 함께하는 느낌

자세한 설계는 [PHASE3.md](PHASE3.md)에 있습니다. 오늘의 강아지와 삶 공유 링크는 서버 없이 먼저 만들 수 있습니다.


- 무지개다리 공원: 다 살고 간 강아지들이 모이는 추모 공간, 촛불과 한마디 (만듦, 실제 반려견도 받음)
- 함께 나눈 삶: 다른 사람이 살아본 생애와 한 줄 소감 (만듦, 오늘의 강아지는 같은 날끼리 묶음)
- 오늘의 강아지: 같은 시드로 모두가 같은 강아지를 살아보기

## 4단계: 넓히기

- 다국어: 일본어, 중국어 번체 우선 (원작이 크게 퍼진 곳)
- 보호소·동물단체 협업: 보호소에서 시작한 생애가 끝나면 실제 입양 정보로 연결
- 일관된 일러스트 스타일로 개체별 외형 표현

## 시장 메모

- 원작은 한 생이 30분~1시간 30분인데도 성공했습니다. 길이보다 의미와 공유 구조가 중요합니다.
- 원작과 비슷해 보이지 않게 이름, 화면, 문구를 분명히 다르게 하고, 영감을 받았다는 사실은 밝힙니다.
- 개 버전의 차별점: 반려인이라는 큰 공감층, 전 연령, 실제 내 강아지와의 연결.
