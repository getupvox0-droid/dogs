# 강아지의 삶 — v3.2 후속 구현과 검증

## 완료 판정 원칙
이 보고서는 이전의 일괄 완료 표시를 대체한다. 코드가 있다는 것, 자동 테스트가 통과한다는 것, 실제 화면에서 사용성이 확인됐다는 것을 구분한다. 1,100개 템플릿 목표와 실제 모바일 화면 검증은 완료로 표시하지 않는다.

## 실제 수정 파일
- `dist/engine.js`, `stories.js`, `world.js`: 일일 진행, 발달, 실종과 재회.
- `dist/behavior.js`, `life-state.js`, `physiology.js`, `decisions.js`: 동기·기억·기질·필요 수치.
- `dist/threads.js`, `opportunities.js`, `life-events.js`: 조건부 상황과 연결 경험.
- `dist/people-world.js`, `neighbors.js`, `family.js`: 사람·시설·주변 동물·친밀한 관계.
- `dist/clinical.js`, `clinical-extra.js`, `health.js`: 진료와 장기 관리.
- `dist/app.js`, `index.html`, `story-runner.js`, `time-config.js`, `chronicle.js`: 표시·시간·기록·엔딩 연결.
- `tests/completion.test.mjs`, `tests/engine.test.mjs`: 조건·회귀·반복률 검사.

## 자료의 적용 범위
ACVS의 슬개골·골절 자료, Merck의 발달·번식·관절·체중 관리, AAHA의 예방 관리 구분을 참고한다. 미국 접종표를 전 세계 실측률로 적용하지 않았다. 사건 발생률, 등급 배정, 회복 기간, 돌봄 점수와 치료 성공률은 게임용 가정이며 임상 예측값이 아니다. 기존 영국 생명표도 다른 국가의 실제 생존율을 보장하지 않는다.

## 미완료와 검증 한계
- 1,100개 직접 검토한 사건 템플릿 목표는 미달성. 이번 4,108개 검사는 조건과 행동의 조합 수이며 4,108개 새 사건을 뜻하지 않는다.
- 국가별 출생·입양·질병의 실측 확률 보정은 미완료. 현재 6개 국가 추첨은 게임 설정이다.
- 주변 동물·사람의 모델은 개별 상태를 갖지만 모든 개체의 완전한 생애·번식·경제 시뮬레이션은 아니다.
- 다른 동물 종은 지원하지 않으며 개의 발달을 다른 종에 적용하지 않는다.
- 이미지는 기존 유한 자산과 명시된 도식 대체를 유지한다. 개체별 무한 이미지 생성은 없다.
- 실제 모바일 브라우저 QA는 현재 환경에 지원되는 브라우저 검증 기능이 없어 수행하지 못했다. 모의 DOM 검사를 실제 화면 검증으로 보고하지 않는다.

## 최종 자동 검사 결과
- 전체 `node --test tests/*.test.mjs`: 102개 통과, 실패 0개.
- 1,000회 출생부터 사망까지 검사: 첫 행동·마지막 행동·기질 가중 행동의 세 정책 사용.
- 동일 질문 반복: 72,884회 질문 중 같은 생애 안의 중복 3,717회, 5.10%. 문장 완전 일치 기준이므로 의미가 비슷한 문장의 반복률을 뜻하지 않는다. 의료상 중요한 재발 질문은 계속 표시한다.
- 서로 다른 사건 순서: 1,000개/1,000개. 나이·사건 ID·선택 행동·목적의 순서로 비교하며 개체 ID만 다른 경우를 세지 않았다. 모든 가능한 삶의 유일성을 증명한 것은 아니다.
- 관측된 선택 유형 89종. 고정 본문 템플릿 개수와 다른 지표다.
- 신규 상황의 조건·행동 조합 4,108건 및 34개 행동 검증.
- 31개 ES 모듈 구문 검사, 상대 모듈 경로 검사, 변경 공백 오류 검사 통과.
- 출생·엔딩·저장·선택 결과·직접 진행 UI는 모의 DOM 검사 통과. 실제 모바일 화면은 미검증.

상세 수치: `dist/data/life-quality.json`. 위 수치는 이번 게임 모델의 결과이며 실제 동물 생존율·입양률 통계가 아니다.
